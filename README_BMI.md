# BMI Calculator

Simple command-line BMI calculator.

Usage
------
Run the script with Python 3:

```
python C:/Users/Admin/Downloads/bmi_calculator.py
```

Follow prompts to choose units (metric or imperial), enter weight and height. The program validates inputs and prints your BMI and category.

Categories
---------
- Underweight: BMI &lt; 18.5
- Normal weight: 18.5 ≤ BMI &lt; 25
- Overweight: 25 ≤ BMI &lt; 30
- Obesity: BMI ≥ 30
